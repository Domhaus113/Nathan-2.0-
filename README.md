# Vets2Pets-Brain

Nathan's permanent knowledge base. Plain-markdown Obsidian vault so nothing is lost between sessions — readable by any AI at any time.

## Folder map

| Folder | What lives here | How it's filled |
|---|---|---|
| `Avatars/` | Customer personas (one file each) | Authored from real avatar source files |
| `Scripts/` | Every script (concept card + hooks + body) | Authored + synced from Creative Tracker |
| `Frameworks/` | Reusable methodology (the "how") | Authored once, refined over time |
| `Performance/` | One file per creative that has run, with real Meta data | Updated from Pipeboard / Meta |
| `Playbooks/` | Product-specific strategy briefs | Authored per product |
| `Decisions/` | Creative decisions log (rationale + outcome) | **Deferred — added once Nathan is built** |

## Conventions
- Every file starts with YAML frontmatter (Obsidian properties).
- Filenames use hyphens, not slashes or spaces (Obsidian-safe).
- Files prefixed `_TEMPLATE_` are blank scaffolds — copy, rename, fill. Do not edit the template itself.
- Status values: `draft` | `active`.
